# 📝 BotSummary

Telegram-юзербот на [Telethon](https://github.com/LonamiWebs/Telethon), который делает краткое саммари переписки в групповых чатах с помощью LLM через [OpenRouter](https://openrouter.ai).

![Python](https://img.shields.io/badge/python-3.12-blue)
![Docker](https://img.shields.io/badge/docker-ready-2496ED)

## Возможности

- 💬 Отвечает `pong` на сообщения `ping` / `пинг`.
- 👋 Пишет приветствие и логирует событие, когда аккаунт добавляют в группу.
- 🧠 Делает саммари последних N сообщений чата по команде `summary` / `саммари`.
- 🐳 Запускается в Docker одной командой.

## Как это работает

Бот работает не через Bot API, а как **обычный пользовательский аккаунт** (юзербот) по протоколу MTProto. Поэтому он может читать историю чатов, в которых состоит. Обычный бот от @BotFather этого не умеет.

1. Вы добавляете аккаунт-бота в группу.
2. Кто-то упоминает его или отвечает на его сообщение и пишет `summary` или `саммари`.
3. Бот читает последние N сообщений, отправляет их в выбранную модель через OpenRouter и отвечает саммари.

> ⚠️ **Важно.** Автоматизация пользовательских аккаунтов нарушает правила Telegram, если использовать её для спама или массовых действий. Аккаунт могут ограничить. Используйте **отдельный аккаунт**, а не личный.

## Что понадобится

- Docker и Docker Compose (или Python 3.12+ для запуска без Docker)
- Отдельный аккаунт Telegram с номером телефона
- Аккаунт на [OpenRouter](https://openrouter.ai) с пополненным балансом

## Установка с нуля

### Шаг 1. Создайте аккаунт Telegram для бота

1. Зарегистрируйте новый аккаунт на отдельный номер (отдельная SIM или виртуальный номер).
2. Задайте **username**: *Настройки → Имя пользователя*. Через него бота будут упоминать в чатах.
3. Желательно поставить имя и аватарку, чтобы участники понимали, кто это.
4. Двухфакторную аутентификацию (облачный пароль) включать не обязательно. Если она включена, понадобится пароль при первом входе.

### Шаг 2. Получите `API_ID` и `API_HASH`

1. Откройте **https://my.telegram.org** (это не `web.telegram.org`).
2. Введите номер аккаунта бота в формате `+79991234567`.
3. Код придёт **в приложение Telegram**, в служебный чат «Telegram», а не по SMS. Введите его на сайте.
4. Откройте **API development tools**.
5. Заполните форму: *App title* и *Short name* (любые, латиницей), остальное можно пропустить. Нажмите **Create application**.
6. Скопируйте **App api_id** и **App api_hash**.

### Шаг 3. Получите ключ OpenRouter и выберите модель

1. Зарегистрируйтесь на **https://openrouter.ai**.
2. Пополните баланс: *Credits*.
3. Создайте ключ: *Keys → Create Key*. Скопируйте его, повторно он не показывается.
4. Выберите модель на **https://openrouter.ai/models** и скопируйте её идентификатор, например `deepseek/deepseek-v4.1-flash`.

### Шаг 4. Скачайте проект

```bash
git clone https://github.com/bondiik/summaryBot.git
cd BotSummary
```

### Шаг 5. Создайте файл `.env`

```bash
cp .env.example .env
```

Откройте `.env` и заполните в соотвествии с комментариями

Правила записи:

- без кавычек;
- без пробелов вокруг `=`;
- без комментариев в конце строки.

### Шаг 6. Первый запуск (вход в аккаунт)

При первом запуске Telegram пришлёт **код подтверждения** в приложение. Его нужно ввести в терминале, поэтому запуск должен быть интерактивным:

```bash
docker compose run --rm --build bot
```

Когда появится запрос `Please enter the code you received:`, введите код из чата «Telegram». Если включена 2FA, введите ещё и пароль.

После входа в консоли появится строка `Бот запущен`, а в папке `data/` создастся файл `userbot.session`. Остановите бота по `Ctrl+C`.

### Шаг 7. Запуск в фоне

Когда файл `data/userbot.session` существует, запускайте так:

```bash
docker compose up -d --build
```

## Как пользоваться

1. Добавьте аккаунт бота в нужную группу.
2. В группе упомяните бота или ответьте на его сообщение и напишите `summary` или `саммари`:

   ```
   @username саммари
   ```

3. Бот прочитает последние `NUMBER_RECENT_MESSAGES` сообщений и пришлёт саммари ответом.

Любой другой текст бот игнорирует. Команда работает только в группах и супергруппах.

## Запуск без Docker

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python bot.py
```

## Безопасность и приватность

- **Никогда не публикуйте** `.env` и `data/*.session`. Файл сессии даёт полный доступ к аккаунту, а ключ OpenRouter привязан к вашему балансу.
- Если ключ или сессия попали в открытый доступ, удалите ключ в OpenRouter и завершите сеанс в Telegram: *Настройки → Устройства*.
- Текст переписки отправляется в OpenRouter и дальше провайдеру выбранной модели. **Предупредите участников чата** об этом.
- Каждый вызов `summary` стоит денег. Следите за балансом на OpenRouter.
- Используйте отдельный аккаунт и не делайте массовых рассылок: за это Telegram ограничивает аккаунты.
